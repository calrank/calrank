# calrank MVP — 1단계 (통합 캘린더)

국내 동호인 스포츠대회(마라톤·자전거·트레일·철인3종·하이록스) 통합 캘린더의 최소 버전입니다.
정적 사이트라 서버 없이 Vercel/Netlify에 바로 배포할 수 있습니다.

## 로컬에서 확인하기

`events.json`을 `fetch`로 불러오기 때문에 `index.html`을 파일로 직접 열면 브라우저 보안 정책 때문에 안 보일 수 있습니다.
아래처럼 간단한 로컬 서버로 띄워서 확인하세요.

```bash
cd calrank-mvp
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 Node가 있다면:

```bash
npx serve .
```

## 배포 (무료)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. [vercel.com](https://vercel.com)에서 GitHub 연동 후 이 저장소를 선택 → Framework Preset은 "Other"로 두고 배포.
   빌드 명령 없이 정적 파일 그대로 서빙되면 됩니다.
3. 무료 서브도메인(`calrank.vercel.app` 형태)으로 바로 접속 가능합니다.

## 지금 상태

- `events.json`에 마라톤온라인·싸이클로라마에서 직접 확인한 실제 대회 12건이 들어있습니다 (마라톤/트레일 8건, 자전거 4건).
- 접수마감일과 찜 수는 각 대회 상세 페이지까지 확인하지 못해 `null`/`0`으로 정직하게 비워뒀습니다. 화면에는 "접수기간 미확인"으로 표시됩니다.
- 하이록스·철인3종 데이터는 아직 없습니다.
- 종목 필터, 접수 D-day(값이 있을 때), 찜하기(세션 내에서만 유지) 동작.

## 다음 단계 (직접 채워야 하는 부분)

1. **대회 일정 자동 수집**
   `scripts/fetch_events.py`에 roadrun.co.kr(마라톤온라인 실제 데이터가 로딩되는 도메인) 기준 실제 크롤링 로직이 구현되어 있습니다.
   다만 이 환경 네트워크 제약으로 실행 테스트는 못 했으니, GitHub Actions에서 `workflow_dispatch`로 먼저 한 번 수동 실행해서
   결과를 검수한 뒤 `.github/workflows/update-events.yml`의 schedule 주석을 해제해 매일 자동화하세요.
   자전거·하이록스·철인3종 소스는 아직 없어서 `fetch_roadrun()` 같은 함수를 추가로 만들어야 합니다.
   - 반드시 각 소스 사이트의 이용약관을 먼저 확인하세요. 대회 "일정 정보"(날짜/장소/종목)만 다루고,
     참가자 개인 기록은 이 스캐폴드로 수집하지 않도록 설계되어 있습니다.

2. **찜하기 영구 저장**
   현재는 브라우저 세션 안에서만 유지됩니다. 로그인 + Supabase 같은 무료 DB를 붙이면 영구 저장이 가능합니다.

3. **개인 기록/랭킹 (2~3단계)**
   Strava OAuth 연동, 사용자 리뷰 기반 대회 랭킹은 이 MVP 이후 별도로 설계합니다.
   자세한 내용은 `calrank_plan.md` 전체 기획안을 참고하세요.
